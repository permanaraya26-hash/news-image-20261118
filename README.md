Entry for the [make.fun](https://make.fun) bounty [Sum up 18 November's world news in one image](https://make.fun/bounty/news-image-20261118) — $250 USDC, top 50 paid.

A program that writes one 1024×1024 image summing up the world's news of Wednesday 18 November 2026 to `/output/entry.png`: a newspaper front page — the Kerch Bridge crippled, Iran–US strikes in the Gulf, Trump bringing the Quad back together in Manila, Cyclone Akvan over the Bay of Bengal, UK sanctions on West Bank settlement builders, and MS Dhoni's IPL retirement.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`. Deterministic: every run writes the same bytes, with no network.
